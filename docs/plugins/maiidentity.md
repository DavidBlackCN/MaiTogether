# MaiIdentity

管理熟悉的人、相处方式和管理员。[上游安装说明](https://github.com/DavidBlackCN/maibot-maiidentity-plugin)

在 WebUI 的插件配置页，给 `identity.people` 添加 QQ 号和称呼，启用该条目。需要执行管理命令的人另填入 `management.admin_accounts`。身份工作区可以预览名单、模板和提示词。

固定身份按账号识别，群昵称不会改变身份。和 [MaiHush](maihush.md) 搭配时，在 Hush 中选择管理员来源 `identity`。麦麦自己的形象资料见 [Self-Identity](self-identity.md)。
