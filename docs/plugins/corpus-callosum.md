# 神经闭环反馈

[项目与安装说明](https://github.com/yufei-pan/maibot-corpus-callosum)

## 简介

当回复模型发现规划内容与聊天实际情况严重不符时，暂不发送，并把理由交回规划模型重新判断。

## 补充说明

当前上游 1.3.5 声明最高支持 Host 1.3.99／SDK 2.16.99，不适用于本项目的 Host 1.4.3／SDK 2.22.1 组合。暂缓安装，等待上游支持后再验证。

先保留默认再审次数和提示词，无需为这项内部反馈添加后台发送权限。若以前在人设里写过“发现规划错误就公开指出”，建议去掉这类要求，避免重新出现当众纠错和连环道歉。

它会用空回复表达拒绝发送。与回复守卫或后处理搭配时，不要让空回复补发功能把这次拒绝变成另一条消息。
