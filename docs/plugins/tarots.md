# 塔罗工坊

[项目与安装说明](https://github.com/A0000Xz/MaiBot-Tarots-Plugin)

## 简介

提供抽牌、牌阵图片和按麦麦语气生成的解牌。

## 推荐配置

当前上游 2.1.0 声明最高支持 Host 1.3.99，暂缓在本项目 Host 1.4.3 组合中安装。支持版本可用后先使用命令入口，关闭关键词自动触发，避免睡眠时先解牌再被发送检查拦截。

## 补充说明

- 先使用默认公版牌组。管理员在插件自己的 `permissions.admin_users` 中设置；没有接入 MaiIdentity 的命令不会自动共用管理员名单。
- 示例配置已允许关键词自动抽牌发送结果。卡面下载和解牌模型仍按插件配置执行，最终消息受睡眠和静音限制。
