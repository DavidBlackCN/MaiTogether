# MaiWeave

负责日程、睡眠、生活经历、主动交流和空间日记。在插件工作区设置作息、时区、模型任务和交流对象。[上游安装说明](https://github.com/ilworkcn/MaiWeave)

MaiTogether 默认通过公开接口询问本次能否发送，无需填写接口名称。配置示例已经允许 MaiWeave 主动分享和向自己的 QQ 空间发布，具体对象和频率仍在 MaiWeave 中设置。建议时区与[日期上下文插件](date-context.md)保持一致。

## 人物与主动交流

- 固定身份称呼在 MaiIdentity 设置。建议在 MaiWeave 的“聊天上下文”关闭“带入人物与纪念日”（`context.people = false`），减少两套人物描述重复或冲突。这会同时关闭人物近况、关系及纪念日的自动提示，不删除记录，也不限制工具读取或主动交流使用这些资料。
- MaiWeave 的亲密等级、聊天唤醒及人物资料仍按上游规则运行，可能随互动变化，不等同于 MaiIdentity 的管理员权限。需要调整某人的唤醒资格时，可在人物资料中手动设置亲密等级；不需要聊天唤醒可关闭“允许聊天唤醒”。
- 主动交流默认关闭，按需开启并选择对象、时段和频率。发送报错时先查看实际聊天记录：上游不能可靠区分所有超时与部分发送结果，后续可能再次选择同一话题；遇到此情况可先关闭主动交流。
- 普通分享默认在 7:00 至 23:00 之间。麦麦答应「到地方告诉你」这类和日程有关的回信，会在允许交流时单独跟进。每日上限大于零时，普通分享用完额度也可能收到这类回信。

## 空间日记

- 空间发布先选择“手动发布”，核对草稿与可见范围；需要自动分享时再选择“日记完成后自动发布”。
- 空间发布使用 SnowLuma 当前登录账号。群静音不影响个人空间，睡眠、忙碌或生活状态不可用时暂停发布。
- 遇到“待核对”时，请先查看实际空间，再到日记详情中确认是否发布成功。
- 使用 SnowLuma 可以发布文字随笔，也可以在 MaiWeave 中开启日记配图。NapCat 的空间发布需要读取 QQ 登录 Cookie，MaiTogether 会拦截这次读取。

## 睡眠和发言

在 MaiWeave 里设置作息即可。普通聊天回复遵循它的对话设置。插件发消息、戳一戳、贴表情和发空间遵循它的主动交流规则。

| 麦麦在做什么 | 普通聊天回复 | 插件主动互动 |
| --- | --- | --- |
| 出行、休闲或用餐 | 可以 | 可以 |
| 学习或工作 | 可以 | 暂停 |
| 午睡，关闭了“午睡期间保持安静”，且在夜间作息以外 | 可以 | 暂停 |
| 夜间睡眠，或开启了午睡静默 | 暂停 | 暂停 |
| 临时醒来准备道晚安 | 只在告别会话回复 | 暂停 |

群静音仍然生效。MaiWeave 无法给出决定时，受管发送会暂停。

基础聊天频率由 MaiBot 设置；主动分享的频率由 MaiWeave 设置。发送检查不会替它们计算新的发言概率。

默认情况下，睡眠期间的消息仍可进入 MaiBot 聊天流程。想减少睡眠时的模型调用，可以在「角色与作息 → 日常作息」分别开启「睡眠时普通私聊跳过 Planner」和「睡眠时普通群聊跳过 Planner」。开启后，对应会话中未唤醒麦麦的普通消息会跳过模型判断，也不进入宿主聊天历史。斜杠命令仍按原流程处理。
