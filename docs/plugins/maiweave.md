# MaiWeave

[上游项目](https://github.com/ilworkcn/MaiWeave) · [适配包构建](../../integrations/maiweave/README.md)

## 简介

负责日程、活动、睡眠、生活经历、主动交流和空间日记。在它自己的配置页或工作区设置作息、时区、模型任务和交流对象。

使用基于 MaiWeave 0.11.4 的配套适配包，构建方法见上方链接。MaiTogether 默认读取生活状态，无需填写接口名称。配置示例已经允许 MaiWeave 主动分享和向自己的 QQ 空间发布，具体对象和频率仍在 MaiWeave 中设置。建议时区与[日期上下文插件](date-context.md)保持一致。

## 身份、近况与分享

- 固定身份称呼在 MaiIdentity 设置；需要允许某人叫醒或影响日程时，在 MaiWeave 人物资料中手动设置亲密等级。这不授予管理员权限。
- 用户近况默认只在来源聊天使用。“跨聊天共享近况”开启后，同一个人的近况可以用于其他聊天。
- 主动分享显示“待核对”时，先查看实际聊天记录，再在工作区确认已发送或未发送。部分发送按已发送处理，避免重复。
- 空间发布先选择“手动发布”，核对草稿与可见范围；需要自动分享时再选择“日记完成后自动发布”。发布结果未知时先查看 QQ 空间，再处理待核对记录。
- 空间发布使用 SnowLuma 当前登录账号。群静音不影响个人空间，睡眠、忙碌或生活状态不可用时暂停发布。
- 当前支持文字生活随笔；好友动态浏览、点赞、评论和配图不包含在这项功能中。

## 睡眠和发言

聊天思考、亲密关系、唤醒和生活循环由 MaiWeave 与 MaiBot 处理。MaiTogether 只在实际对外发送前检查生活状态：

| 公开状态 | 对外动作 |
| --- | --- |
| 正常空闲、清醒休闲、休息、用餐等活动 | 允许，仍检查群静音和权限 |
| 学习、工作、出行 | 暂停 |
| 睡眠，且没有有效的临时唤醒 | 暂停 |
| 接口异常、状态过期或无法确定 | 暂停 |

基础聊天频率由 MaiBot 设置；主动分享的频率由 MaiWeave 设置。发送检查不会替它们计算新的发言概率。

睡眠期间消息仍可以进入官方聊天和记忆流程，模型也可能被调用。唤醒条件按 MaiWeave 自身规则执行，与 MaiIdentity 的管理员身份不是一回事。

## 状态判断

睡眠判断使用 MaiWeave 的 `effective_sleeping`。临时唤醒到期后，如果原睡眠仍有效，即使续睡日程尚未生成，也会暂停对外动作。正常空闲可以发送。

MaiTogether 在实际睡眠期间统一暂停发送，包括午睡。MaiWeave 的“午睡期间保持安静”开关影响自身聊天规则，关闭它时，统一发送检查仍按实际睡眠状态执行。

每次发送检查都会重新查询，默认接受 180 秒内的查询结果。精力、心情等数据的保存时间可以较早。活动结束、唤醒到期或下一项活动开始时，旧查询结果会失效。

MaiWeave 更新较快，更新适配包前需要核对状态、交付和资料接口，并重新测试。维护验证方法见[维护说明](../maintenance.md)。
