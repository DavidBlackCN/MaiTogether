# MaiWeave

[上游项目](https://github.com/ilworkcn/MaiWeave) · [接口与维护测试](../../integrations/maiweave/README.md)

## 简介

负责日程、活动、睡眠、生活经历、主动交流和空间日记。在它自己的配置页或工作区设置作息、时区、模型任务和交流对象。

按上游说明安装和更新原版 MaiWeave。MaiTogether 默认读取它的公开生活状态，无需填写接口名称。配置示例已经允许 MaiWeave 主动分享和向自己的 QQ 空间发布，具体对象和频率仍在 MaiWeave 中设置。建议时区与[日期上下文插件](date-context.md)保持一致。

## 身份、近况与分享

- 固定身份称呼在 MaiIdentity 设置。建议在 MaiWeave 的“聊天上下文”关闭“带入人物与纪念日”（`context.people = false`），减少两套人物描述重复或冲突。这会同时关闭人物近况、关系及纪念日的自动提示，不删除记录，也不限制工具读取或主动交流使用这些资料。
- MaiWeave 的亲密等级、聊天唤醒及人物资料仍按上游规则运行，可能随互动变化，不等同于 MaiIdentity 的管理员权限。需要调整某人的唤醒资格时，可在人物资料中手动设置亲密等级；不需要聊天唤醒可关闭“允许聊天唤醒”。
- 主动交流默认关闭，按需开启并选择对象、时段和频率。发送报错时先查看实际聊天记录：上游不能可靠区分所有超时与部分发送结果，后续可能再次选择同一话题；遇到此情况可先关闭主动交流。
- 空间发布先选择“手动发布”，核对草稿与可见范围；需要自动分享时再选择“日记完成后自动发布”。发布结果未知时先查看 QQ 空间，再处理待核对记录。
- 空间发布使用 SnowLuma 当前登录账号。群静音不影响个人空间，睡眠、忙碌或生活状态不可用时暂停发布。
- 空间发布被拦截时，上游也可能显示“待核对”。查看实际空间后，再通过日记详情中的核对操作处理。
- 当前支持文字生活随笔；好友动态浏览、点赞、评论和配图不包含在这项功能中。

## 睡眠和发言

聊天思考、亲密关系、唤醒和生活循环由 MaiWeave 与 MaiBot 处理。MaiTogether 只在实际对外发送前检查生活状态：

| 公开状态 | 对外动作 |
| --- | --- |
| 正常空闲、清醒休闲、休息、用餐等活动 | 允许，仍检查群静音和权限 |
| 学习、工作、出行 | 暂停 |
| 睡眠，且没有有效的临时唤醒 | 暂停 |
| 接口异常、状态过期或无法确定 | 暂停 |

基础聊天频率由 MaiBot 设置；主动分享的频率由 MaiWeave 设置。发送检查不会替它们计算新的发言概率。

睡眠期间消息仍可以进入官方聊天和记忆流程，模型也可能被调用。唤醒条件按 MaiWeave 自身规则执行，与 MaiIdentity 的管理员身份不是一回事。

## 状态判断

睡眠判断使用 MaiWeave 的 `effective_sleeping`。临时唤醒到期后，如果原睡眠仍有效，即使续睡日程尚未生成，也会暂停对外动作。正常空闲可以发送。

MaiTogether 在实际睡眠期间统一暂停发送，包括午睡。MaiWeave 的“午睡期间保持安静”开关影响自身聊天规则，关闭它时，统一发送检查仍按实际睡眠状态执行。

每次发送检查都会重新查询，默认接受 180 秒内的查询结果。精力、心情等数据的保存时间可以较早。活动结束、唤醒到期或下一项活动开始时，旧查询结果会失效。

接口约定与已核验提交见[维护记录](../../integrations/maiweave/README.md)。MaiWeave 可独立更新；若公开状态接口发生变化，MaiTogether 会暂停受影响动作，需重新核验接口。维护测试见[维护说明](../maintenance.md)。
