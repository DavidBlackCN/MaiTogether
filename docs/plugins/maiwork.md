# MaiWork

在后台接单、调用 Agent 和工具，通过群消息或文件交付结果。可从 MaiBot 插件市场安装，或按[上游安装说明](https://github.com/CharTyr/MaiWork#快速开始)安装原版。

## 开始使用

在 MaiWork 配置里启用插件，把群号加入服务群，再打开工作台配置模型和该群的审批人。群内的 `/mw 批准` 和 `/mw 拒绝` 使用 MaiWork 的本群名单。需要某位 MaiIdentity 管理员也能批任务时，将其加入相应群的审批名单。

麦麦休息期间，MaiWork 仍可继续或开始工作并消耗模型额度。在 MaiTogether 管理的群里，发往 QQ 的消息与群文件仍须通过生活状态和群静音检查。发送失败后的重试或改用其他交付方式由 MaiWork 处理。

## 文件和外部工具

MaiWork 可以把报告上传到 here.now，发送群文件失败时也可能改用网页交付。关闭 `console.herenow_share` 只会关闭工作台分享。处理私密文件前，请先确认允许的交付方式；需要保证文件留在服务器时，应在部署环境限制公开上传。

使用 MCP 时，为每个已启用的服务明确填写允许调用的工具。原版会在工具名单为空时导入服务提供的全部工具。
