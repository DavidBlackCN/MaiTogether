# Reply Integrity

[项目与安装说明](https://github.com/Zerlight/maibot-reply-integrity)

## 简介

当前上游 1.3.2 声明最高支持 Host 1.3.19，不适用于本项目的 Host 1.4.3 组合。暂缓安装，等待上游支持后再验证。

让 MaiBot 的回复器拿到完整事实，同时摆脱“A言gent语”，用自己的口吻自然说话。

插件**不增加模型调用、不修改 MaiBot 核心源码、无需额外 capability 授权或 API 密钥**，运行期仅依赖官方 SDK 与 Python 标准库，并提供 WebUI 热更新配置。
